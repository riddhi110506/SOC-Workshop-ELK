# Elastic Agent Setup – Windows Server 2019

> **Windows Server 2019 – Endpoint**

## Step 1: Open Kibana Fleet

Open Kibana in your browser.

Navigate to:

**☰ Menu → Management → Fleet → Agents**

---

## Step 2: Add an Agent

Click:

**Add agent**

Select the appropriate agent policy for the Windows endpoint.

Choose:

**Windows**

Kibana will display the Elastic Agent enrollment instructions.

---

## Step 3: Download Elastic Agent

Open a browser on the Windows Server 2019 machine.

Download the Elastic Agent ZIP file.

Example:

```text
https://artifacts.elastic.co/downloads/beats/elastic-agent/elastic-agent-8.19.19-windows-x86_64.zip
```

---

## Step 4: Extract Elastic Agent

Extract the downloaded ZIP file.

For example, extract it to:

```text
C:\Elastic\
```

Open PowerShell as **Administrator**.

Navigate to the extracted Elastic Agent directory:

```powershell
cd C:\Elastic\elastic-agent-8.19.19-windows-x86_64
```

---

## Step 5: Verify the Elastic Agent Files

Run:

```powershell
dir
```

You should see files including:

```text
elastic-agent.exe
README.md
NOTICE.txt
```

---

## Step 6: Get the Enrollment Command

Return to **Ubuntu**:

**Kibana → Fleet → Agents → Add agent**

Select:

**Windows**

Kibana will display the Elastic Agent enrollment command.

The command contains:

- Fleet Server URL
- Enrollment token

Copy the complete command provided by Kibana.

> **Important:** Use the exact enrollment command generated by your Kibana Fleet page.

---

## Step 7: Install and Enroll Elastic Agent

Open **PowerShell as Administrator** on Windows Server 2019.

Navigate to the Elastic Agent directory:

```powershell
cd C:\Elastic\elastic-agent-8.19.19-windows-x86_64
```

Paste the enrollment command provided by Kibana.

The command will be similar to:

```powershell
.\elastic-agent.exe install --url=https://<Fleet-Server-IP>:8220 --enrollment-token=<ENROLLMENT-TOKEN>
```

Replace the placeholders only if required.

Press **Enter** and wait for the installation to complete.

---

## Step 8: Verify Elastic Agent

After installation, check the Elastic Agent service:

```powershell
Get-Service "Elastic Agent"
```

The service should show:

```text
Status : Running
```

---

## Step 9: Verify Agent in Kibana

Return to **Ubuntu**:

**Kibana → Management → Fleet → Agents**

Locate the Windows Server 2019 endpoint.

The agent should appear as:

```text
Healthy
```

If the Windows agent appears as **Healthy**, the Elastic Agent has been successfully enrolled.

---

## Elastic Agent Setup Completed

The Windows Server 2019 Elastic Agent is now enrolled with Fleet Server and ready to collect endpoint data.

```text

        |

```

✅ **Elastic Agent installation and enrollment completed successfully.**
