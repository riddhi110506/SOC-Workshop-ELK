# Lab 15: Detecting PowerShell Network Connections Using ELK

## Objective

The main objective of Lab 15 is to monitor and detect network connections made by trusted Windows binaries, such as PowerShell, using the ELK Stack and Sysmon.

This helps identify suspicious activities where legitimate system tools are used to communicate over the network.

---

## Step 1: Open Kibana Discover

In Kibana, open:

**Kibana → Discover**

Select the following:

**Data View:**

```text
logs-*
```

**Time Range:**

```text
Last 15 minutes
```

---

## Step 2: Generate Network Activity

On **Windows Server 2019**, open **PowerShell as Administrator**.

Run:

```powershell
Invoke-WebRequest -Uri "https://example.com" -OutFile "$env:TEMP\example.html"
```

Then run:

```powershell
Invoke-WebRequest -Uri "https://www.microsoft.com" -OutFile "$env:TEMP\microsoft.html"
```

These commands make PowerShell, a trusted Microsoft binary, connect to the Internet.

---

## Step 3: Verify the Event

Wait approximately **30 seconds**.

Go back to:

**Kibana → Discover**

Run the following KQL query:

```text
winlog.channel:"Microsoft-Windows-Sysmon/Operational" AND event.code:"3"
```

You should see a new event.

---

## Step 4: Create the Detection Query

Here we will take a copy of any log and find out:

- `event.code`
- `event.provider`
- `winlog.channel`
- `winlog.event_data.Image`
- `DestinationIp`
- `DestinationPort`

Use these fields to analyze the network connection event and identify the process responsible for the connection.

---

## Result

PowerShell network connections can be detected using **Sysmon Event ID 3** in Kibana.

The ELK Stack can therefore be used to monitor network activity generated by trusted Windows binaries such as PowerShell.
