# Lab 17 – Detect Network Connections (Sysmon Event ID 3)

## Step 1: Generate a Network Connection

On **Windows Server 2019**, open **PowerShell** and run:

```powershell
Invoke-WebRequest https://example.com
```

---

## Step 2: Search in Kibana

Open:

**Kibana → Discover**

Run the following KQL query:

```text
event.code:3
```

---

## Step 3: Create the Detection Query

Here we will take a copy of any log and find out:

- `event.code`
- `event.provider`
- `winlog.channel`
- `winlog.event_data.Image`
- `DestinationIp`
- `DestinationPort`

Use these fields to analyze the event and identify the process responsible for the activity.


---

## Result

The network connection generated by PowerShell can be detected using **Sysmon Event ID 3** in Kibana.
