🔐 ELK Stack – Incident Detection

📌 Overview

This module demonstrates the implementation of the ELK Stack as a SIEM platform for security monitoring and incident detection.
The lab environment collects security events from a Windows system, processes and stores the logs, and uses Kibana for searching, analysis, visualization, and investigation.

🎯 Objective

The main objective is to understand how a SIEM works by building an ELK-based environment.
The implementation focuses on collecting Windows security events using Sysmon and Elastic Agent, storing the events in Elasticsearch, and analyzing them using Kibana.

 **What is ELK?**

ELK Stack is a collection of open-source tools used to collect, store, search, analyze, and visualize logs.
ELK is commonly used as a SIEM solution for security monitoring and incident detection.

ELK stands for:

E – Elasticsearch

L – Logstash

K – Kibana

**What does ELK do?**

Collects logs from different systems.

Stores logs in one central location.

Allows fast searching and analysis of logs.

Displays logs using dashboards and visualizations.

**Elasticsearch**

Elasticsearch is the component used to store and search the collected logs.
It provides a centralized location where security events can be stored and searched efficiently.
In our ELK implementation, logs collected from the Windows system are sent to Elasticsearch, where they can be searched and analyzed.

**Logstash**

Logstash is one of the components of the ELK Stack used for processing and handling log data.
It is part of the ELK architecture and is associated with collecting and processing log information before it is analyzed and visualized.

**Kibana**

Kibana is the visualization and analysis component of the ELK Stack.
It allows security analysts to:

Search logs.

Analyze security events.

Create visualizations.

Create dashboards.

Monitor system activity.

In our implementation, Kibana is used to view and analyze the logs collected from Windows systems.

**Elastic Agent**

Elastic Agent is used to collect logs from the Windows system and send them to Elasticsearch.

In our ELK workflow, Elastic Agent collects the security logs generated by the Windows system and forwards them for centralized storage and analysis.
The Windows Server generates security logs. Elastic Agent collects those logs and sends them to Elasticsearch. Elasticsearch stores the logs, and Kibana displays them in dashboards.

**Sysmon**

Sysmon (System Monitor) is a Microsoft Sysinternals tool that records detailed Windows system activities and generates security logs.
These logs help detect suspicious behaviour and cyber threats.

**Why do we use Sysmon?**

Sysmon provides detailed information about Windows system activity, including:

Process Creation

Network Connections

File Creation

Registry Changes

Process Termination

These events provide useful information for a SOC analyst during security monitoring and incident investigation.
